# 📊 Customer Churn Prediction Dashboard

A Machine Learning web application built using **Python** and **Streamlit** to predict whether a bank customer is likely to churn. This dashboard provides data analysis, preprocessing, model training, model comparison, visualization, and customer prediction in an interactive interface.

---

## 🚀 Features

- 🏠 Home Dashboard
- 📂 Dataset Analysis
- 🧹 Data Preprocessing
- 🤖 Train Multiple Machine Learning Models
- 📊 Model Comparison
- 🔮 Customer Churn Prediction
- 📈 Interactive Visualizations
- ⬇ Download Best Model
- ℹ About Section

---

## 📊 Dataset

**Dataset:** Churn_Modelling.csv

Features include:

- Credit Score
- Geography
- Gender
- Age
- Tenure
- Balance
- Number of Products
- Has Credit Card
- Active Member
- Estimated Salary

**Target Column**

- Exited (0 = Stay, 1 = Churn)

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/your-repository.git
```

Go to project folder

```bash
cd Customer-Churn-Prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
